# 飞行读出

飞行使用当前模型的完整放电记录。感觉输入仍只进入感觉通路；没有随机起飞、定时起飞或直接给运动神经元添加输入。

| 身体接口 | MaleCNS 类型 | 作用与边界 |
| --- | --- | --- |
| 快速起飞 | DNp01 / GF | 读取原始放电事件，避免 80 ms 平滑抹掉短促脉冲。10 ms 返回周期仍不能保留亚毫秒时序。 |
| 其他起飞路径 | DNp11；DNp02 + DNp04 | DNp11 事件，或 50 ms 窗口内准备与跳跃群共同活动。方向映射和窗口是简化解码设置。 |
| 飞行肌动力 | DLMn a, b；DLMn c-f；DVMn 1a-c；DVMn 2a, b；DVMn 3a, b | 全量图左右各 12 个运动神经元；平均放电驱动异步肌激活，不将每次神经放电画成一次振翅。 |
| 空中调节 | DNg02_a 至 DNg02_g | 左 15、右 14 个下行神经元；左右差调节偏航。它们本身不触发起飞，也不替代飞行肌运动神经元。 |
| 降落 | DNp07、DNp10 | 只在空中解释为降落读出。降落姿态到降低升力的转换是身体模型设置。 |

这些群体均排除在背景直接输入和纯感觉入口之外。轻量图同样通过自身元数据建立映射；任何缺失群体输出为零，不伪造神经元。

## 身体模型

步行保留原七通道。飞行另从 `firing/counts` 解码；接口仍兼容原七通道客户端。飞行肌放电率使用 80 ms 平滑，动力目标为 `tanh(meanHz / 5)`，激活上升、下降时间常数分别为 0.442、1.79 s。后两个时间常数参考 [Gordon 与 Dickinson 的肌肉动力研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC1449689/)；归一化增益和升力映射尚未生理校准。

起飞事件给予 80 mm/s 的竖直初速度。没有肌肉动力时只产生约 0.33 mm 的短跳。动力足够时，简化升力控制器维持约 3 mm 高度；升力上限受神经肌激活限制，前进速度为 `24 × activation` mm/s。模型使用 1 ms 物理子步、重力与地面接触。着地后有 200 ms 冷却。没有原先的 0.9 s 强制飞行终止；神经动力消退或降落群活动可使其落地。此处的肌激活不是测量得到的钙浓度，也不是逐肌肉力学仿真。

位置、方向与高度再影响下一次双侧光照、岩石遮挡、气味和食物接触采样。视觉仍是光强代理，没有完整视网膜、光流和飞行本体感觉。能够飞行不等于已经具备可靠避障或趋光；世界边界只约束位置，不替果蝇计算转向。

## 验证

`node --test fly-host/tests/flight.test.js` 检查类型映射、感觉与背景排除、单 GF 事件、只有肌动力不能起飞、有动力可维持飞行、失去动力回落、降落与重置。

`node cloud/tools/check-autonomy.js` 通过标准接口运行全量模型，比较背景、感觉、遮挡、光源方向、切断传播，以及将飞行肌输出置零的因果对照。后者仅属于验证工具，页面没有该人工动作路径。5 秒试验额外检查默认感觉条件出现动力飞行；它不检验动物行为学上的自然起飞概率。

[RTX 4090 D 实测记录](validation/flight-cuda.json)包含各群放电率、离地时间、动力飞行时间和峰值高度。肌输出切断与全网络切断分别验证身体映射与神经传播。零环境但保留中间神经元背景时也可能飞行，不能将所有飞行归因为外界刺激。
