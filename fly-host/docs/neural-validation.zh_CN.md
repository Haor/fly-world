# 神经实现验证

验证日期：2026-09-08。结论：已测范围内，基础 LIF 方程、连接方向和延迟符合当前实现约定；修复了暂停与结果接收的调度问题。当前系统仍是连接组驱动的演示模型，不能据此宣称真实果蝇行为已被复现。

## 已验证

| 检查 | 结果与范围 |
| --- | --- |
| 数据完整性 | 27 个压缩数据分片 SHA-256 与清单一致；166,700 个唯一神经元、25,582,938 条边、124,177,617 个突触；CSR 边界、索引和计数检查通过 |
| 兴奋 / 抑制 | 单脉冲响应与解析解对照，400 个时间步内电位误差小于 0.0001 mV |
| 延迟 | 脉冲在 18 个 0.1 ms 步之后交付，对应 1.8 ms；交付前无突触电流 |
| 不应期 | 普通神经元 2.2 ms 不应期、拒绝期间输入，以及直接刺激目标的不应期例外通过测试 |
| CPU / GPU | 浏览器启动时执行 257 神经元小图一致性测试；每批 GPU 群体输出与返回计数的 CPU 解码比较。未完成整个连接组跨随机种子的逐神经元一致性比较 |
| 完整本地子图闭环 | 固定种子 1，12 秒神经时间：进食累计约 1.05 秒，之后继续运动，发生 3 次起飞。接触味觉、逼近逃逸、感觉关闭、零输入和突触传播关闭对照通过 |
| 数据接收 | 拒绝时钟跳步、NaN 放电率、无效索引、重复 ID 和不一致计数；重复或旧代次响应不能推进身体 |

闭环中的累计“距离”来自运动解码器，含边界阻挡时的尝试位移，不可直接当作实际轨迹长度。界面观察记录的距离另按坐标变化计算。固定种子轨迹不是一般性成功率或长期稳定性证据。

## 本次修复

- 暂停前已发出的计算批次可能继续推进画面。现在暂停时暂存该批次，恢复后再应用；重置丢弃暂存结果。
- 之前未在仿真入口校验累计 tick，也没有拦截重复返回。现在只消费有效的待处理批次，并校验时间、维度与计数。
- 旧代次计算错误不再中断已经重置的新代次。

## 与参考实现的关系

[Shiu 等人的参考代码](https://github.com/philshiu/Drosophila_brain_model/blob/main/model.py)使用简化 LIF 方程，静息 / 阈值电位 -52 / -45 mV，膜与突触时间常数 20 / 5 ms，延迟 1.8 ms，不应期 2.2 ms，每突触权重 0.275 mV。直接 Poisson 刺激目标取消不应期。当前基础方程和这些参数沿用了这套约定；本次没有运行 Brian2 做相同随机输入下的端到端复现。

该[论文](https://www.nature.com/articles/s41586-024-07763-9)基于 FlyWire 脑连接组，对部分感觉运动预测做了实验验证。本项目使用 MaleCNS 保留子图，不能直接继承论文的生物学准确性结论。

## 尚未解决的模型限制

- 本地数据排除了 superclass 缺失的注释行，是保留子图，不等于全部原始连接数据。
- 组胺 / 未知递质无快速输出，多巴胺、章鱼胺与血清素统一按兴奋符号处理。没有受体特异性、慢调制或真实代谢机制。
- 视觉绕过视网膜，以人工逼近特征刺激 LC4 / LPLC2；嗅觉采用双侧采样与简化适应。可选寻食辅助由人工编写，不能当作连接组自主寻食的证据，详见[寻食说明](foraging.zh_CN.md)。
- 辅助实验模式中的 LC9 持续输入与 DNa02 转向偏置是人工探索驱动。直接刺激 DNa02 属于运动输出通路，不能把这部分转向宣称为网络自发决策。
- 边界碰撞只约束位置，不替网络决定转向；输出持续指向边界时可能原地停留，尚无可靠自主避障。
- 饥饿、精力、身体解码与接触进食条件是工程规则；精力消耗按解码速度判定，阻挡时也可能消耗，属于当前需求模型约定。
- CPU 顺序浮点累加与 GPU 整数汇总后缩放不保证全图逐位一致；阈值附近需要进一步量化。没有学习、神经可塑性或长期多种子行为验证。

## 纯感觉模式与 CUDA

当前默认纯感觉模式，人工步行、转向和逼近群体输入均为零，前端和服务端都拒绝直接脉冲。光照与遮挡通过双侧 L1/L2 早期视觉代理输入；组胺光受体传递与完整视网膜尚未建模。该模式不构成自主寻食或生物学准确性的证明。

可选 PyTorch 后端遵循既有 LIF 更新顺序。固定种子的 800 步小图对照覆盖计数、膜电位、兴奋、抑制、延迟与重置，已在 PyTorch CPU 通过。真实 CUDA 硬件执行和全图长期逐脉冲一致性仍需验证，见 [Windows CUDA 验收](../../cloud/docs/cuda-windows.zh_CN.md)。
