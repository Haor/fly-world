# 物理感觉闭环与科学边界

## 已实现的闭环

全量模式由同一服务进程推进：环境 → 感觉转导 → MaleCNS 神经动力学 → 运动神经元读出 → MuJoCo 关节受力 → 身体位置、关节和接触 → 下一轮感觉输入。网页接收物理姿态，不在全量模式中生成步态或翼振。轻量 WebGPU 仍使用近似身体，不能与这条物理路径的验证混为一谈。

身体资产来自 [flybody](https://github.com/TuragaLab/flybody)，固定提交 `d015e9bfe441bd90ae431bac24c55cb74bdbce26`，许可证 Apache-2.0。只使用身体资产，未使用其强化学习策略。原项目的运动表现不能作为当前神经驱动方式的验证证据。

神经与感觉群体身份来自 [MaleCNS 官方注释](https://male-cns.janelia.org/download/)。`sensorimotor.json.gz` 保留来源文件 SHA-256、字段和格式版本。全量节点集合仍是 211,577 个官方注释节点的诱导子图，不含原始连接表的所有未注释片段。

## 仍然存在的模型假设

| 部分 | 当前实现 | 未验证之处 |
|---|---|---|
| 神经动力学 | 项目自有自适应放电模型、递质符号和连接权重 | 连接组不提供每个细胞的完整电生理参数；未逐细胞拟合 |
| 视觉 | 官方 L1/L2 眼柱位置映射到视线，按实际头部姿态采样光照与运动图案 | 视轴映射、ON/OFF 分配和脉冲频率转导是代理；不等于完整视网膜或真实分级电位 |
| 嗅觉 | 实际双触角位置采样浓度场，加入风向与适应 | 只覆盖 ORN_DM1，浓度和频率增益未拟合，没有完整受体谱 |
| 味觉 | 口器接近食物表面时输入 LB3b/LB3c | 接近判据是简化接触代理，没有完整摄食和消化模型 |
| 风觉 | 相对气流映射到 JO 群体 | 感受器方向性和响应曲线未校准 |
| 本体与触觉 | 用关节状态和爪接触传感器驱动对应神经入口与侧别的感觉细胞 | 未区分所有感受器亚型及其方向、阈值、适应 |
| 肌肉 | 按注释类型、侧别和体节映射 268 个运动神经元到 32/78 个执行器 | 力矩符号、力臂、频率—力关系与协同作用未校准；其余执行器不主动驱动 |
| 飞行 | MuJoCo 空气作用与翼关节力矩 | DLM/DVM 到翼力矩是替代映射；没有已验证的异步飞行肌—胸部振荡机制，不能保证自主飞行 |
| 代谢 | 未实现 | 全量物理模式不显示虚构的饥饿、精力百分比 |

没有直接按 DN 活动赋值步行速度、转向速度、起飞冲量或目标高度。该路径也没有随机背景注入、人工寻食导航、预制步态或生成翼振。感觉转导、肌肉和物理参数仍属于人工建立的科学模型；目前不能声称“完全没有人工建模”或“还原了一只活果蝇”。

物理场景目前只有平面、边界、食物和岩石。像素岛中的水面、树和其他装饰不具有对应的完整材料、流体或碰撞模型。刺激条纹和逼近物体是实验视觉场，不是像素画面逐像素形成的眼部图像。

## 数值与时间

神经和物理步长均为 0.1 ms，每 10 ms 耦合一次。身体使用资产原始 Euler 积分器。测试发现将物理步长增加至 0.2 ms 会显著改变轨迹，不能把该设置当作等价的性能优化。即使无数值警告，也不代表轨迹已收敛。精确飞行还需要更细的控制耦合、肌肉校准和步长收敛实验。

RTX 4090 D 测试中，包含当前身体的闭环约为 0.26–0.28×；给链路增加单向 150 ms 延迟后约为 0.28×。这表明推进不依赖每轮网络往返，但完整闭环尚未实时。该数据与此前只含神经计算的近实时测量不是同一工作负载。MuJoCo 的 CPU 计算占主要耗时，GPU 型号不能单独决定闭环性能。

## 验证方法

物理单测检查无运动输出时没有主动受力、运动读出与肌肉消融的因果关系、逃逸神经事件不会直接设置跳跃、关节变化产生感觉反馈、头部姿态改变视网膜采样，以及接触快照序列化。

`cloud/tools/experiment-world.js` 使用固定随机种子，按服务端神经时钟对每种条件运行 2 秒。条件包括明暗、相反方向条纹、近距离气味、风和逼近物体，以及关闭感觉、关闭传播和关闭肌肉的对照。记录放电数、运动读出、物理位置和驱动范数。路径长度来自观察帧，是采样估计。

可支持的最低结论是感觉变化能否改变神经活动，以及运动变化是否依赖传播和肌肉驱动。要声称自然行为，还需重复验证方向特异的视动转向、面向气味源的趋近、合理时延的逃逸，以及稳定协调的步行或飞行。目前这些生物行为验收尚未通过。出现位移、滑动、翻滚或离地都不能自动算作自然步行或飞行。

## 本次成对实验

[完整机器可读结果](../../cloud/validation/physical-loop-2026-09-09.json)记录 20 次运行、种子、环境参数和实现文件哈希。两次基线分别产生 301,626 和 299,862 次放电；关闭全部感觉后均为 0。关闭传播后仍有 62,222 / 62,163 次感觉输入放电，但主动驱动为 0；关闭肌肉后神经仍活动，驱动同样为 0。

基线采样路径约 46.6 / 31.2 mm；三个消融条件约 3.6–4.4 mm，主要来自被动物理运动。环境条件改变了放电与轨迹，但仅两个种子不足以证明方向性、趋食或自然逃逸。风条件的一次“离地”也不能证明自主飞行。
