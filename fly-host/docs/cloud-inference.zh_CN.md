# 本地与远程推理接口

观测站使用同一套接口连接本机 PC、局域网 PC 或云端服务。当前协议为 `fly-world-neural/2`，感觉编码为 `population-hz/3`；更新时必须同时更新前后端。

- [Windows CUDA 安装与验收](../../cloud/docs/cuda-windows.zh_CN.md)
- [CPU、Docker 与跨机部署](../../cloud/docs/deployment.zh_CN.md)
- [神经空间图与官方骨架](anatomy.zh_CN.md)

页面选择轻量或全量后，服务返回相应的全部节点元数据。全量活动不再裁剪到浏览器轻量模型的 ID 集合。模型、后端或输入方式切换会结束旧会话；令牌只在当前连接使用，不存储。

纯感觉模式只允许味觉、双侧嗅觉与双侧早期视觉输入。步行、转向和逼近群体的人工输入必须为零，直接脉冲也被服务拒绝。辅助实验模式保留这些操作。浏览器计算感觉适应，服务不得重复编码。

前端接收全模型放电统计和七个运动读出群体的平均放电率。身体与环境仍由观测站更新；推理服务不返回食物方向或运动命令。协议支持检查单个节点的上游连接，这项操作不推进神经时间。
