# 自主动力学与感觉闭环

页面默认使用“纯感觉”输入和“自主动力学 · 实验”。光照、遮挡、触角气味、食物接触产生感觉输入，连接组传播后，由选定运动群体的实际放电驱动身体。运动改变位置和朝向，下一批重新采样环境。没有食物方向直接控制转向，也没有最低速度或随机行走指令。

“参考 LIF”保留原有电流型更新规则；“自主动力学”是独立的实验配置，不能把其参数或行为归因于原始 Shiu 模型。两种配置都可使用轻量／全量图及 CPU／WebGPU／CUDA 支持范围内的计算后端。

## 神经更新

实验配置把兴奋、抑制分别保存为非负电导 `gE`、`gI`（单位 ms⁻¹）。漏电导 `gL = 1/20`，静息电位 −52 mV，兴奋反转电位 0 mV，抑制反转电位 −75 mV。每个 0.1 ms 步长中暂时固定电导：

```
k = gL + gE + gI
V∞ = (gL × −52 + gE × 0 + gI × −75) / k
Vnext = V∞ + (V − V∞) × exp(−k × 0.1)
```

随后电导按 5 ms 时间常数衰减。突触事件仍经过 1.8 ms 延迟。兴奋／抑制电导增量分别为 `synapseCount × 0.275 / (20 × 52)` 和 `synapseCount × 0.275 / (20 × 23)`。转换匹配原模型在静息点附近的输入斜率；这是建模约定，不是实测单突触电导。它让抑制作用趋向反转电位，而非持续把电压推到极端负值。

阈值为 `−45 + adaptation` mV。非外部频率钳制的神经元每次放电使适应量增加 2 mV，适应按 200 ms 时间常数衰减。重置清空电导、适应、不应期和延迟事件。外部感觉保留原有 68.75 mV Poisson 事件及感觉入口的不应期约定。

## 背景活动与运动读出

可关闭的背景输入为每个目标神经元独立的 40 Hz 随机事件，每次增加 3 mV。它只投向 `cb_intrinsic`、`ol_intrinsic`、`vnc_intrinsic`，排除 L1/L2 感觉入口及全部已选运动读出；不投向感觉、下行或运动类别。固定种子和独立随机流保证对照可重现。关闭环境输入不会关闭背景；“零输入对照并重置”同时关闭二者。

实验运动解码接收同样七个群体的放电率。步行和转向取消原先针对强刺激设置的 6/15 Hz 死区，响应低频活动；步行饱和尺度为 12 Hz，转向为 20 Hz。零放电对应零运动。身体仍使用简化运动学和接触约束，尚非逐肌肉仿真。

这些背景、适应、反转电位和读出参数均是实验设置。保留连接数量不意味着参数已经过生理验证。

## 验证与限制

- 小图验证：零输入静息、抑制电位边界、适应与重置、背景目标范围、切断传播后运动读出归零、低频运动解码。
- CPU／WebGPU：启动时对两种配置检查放电、膜电位与延迟状态。
- CPU／CUDA：`cloud/tools/check-torch.py --profile adaptive --device cuda` 执行固定种子 800 步对照。
- 全量感觉闭环：`cloud/tools/check-autonomy.js` 在相同种子下比较零输入、仅背景、环境、左右光源和切断传播。它检查运动和感觉对下游活动的影响，不把一次靠近食物解释为寻食成功。

视觉目前仍为双侧 L1/L2 光强代理，嗅觉仍为静态气味场。没有完整视网膜、气味湍流、学习或经过验证的趋光／寻食策略。全图长期逐脉冲跨后端一致性也未得到证明。

## 已记录的 CUDA 对照

[机器可读结果](validation/adaptive-cuda.json)使用全量 211,577 节点、种子 1／7／19，在 RTX 4090 D、Python 3.12、PyTorch 2.5.1+cu124 上运行。三个种子在背景与感觉条件下均有移动；静息和切断传播对照的位移及运动输出均为零。改变光源方向会改变下游活动，但尚未证明一致趋光。一秒感觉条件下的位移为 1.19–1.37 mm，纯计算速度约为每秒墙钟时间推进 0.10 秒神经时间，尚非实时。
