# Fly World

Fly World 是一个口袋栖息地，包含小型像素果蝇、树、水塘、蘑菇和果实。使用 16 色画面与 AI Passport 三键交互。

## 操作

- 上、下选择动作，确定执行。
- 本地模式：FEED 放置食物；PLAY 短暂飞行；REST 切换休息。
- 神经模式：WALK、LEFT、RIGHT、FLY 刺激相应 MaleCNS 神经群。PAUSE 切换仿真暂停；RESET 重置神经仿真。
- 长按确定：本地模式切换休息，神经模式选择并触发 PAUSE。

本地饱食度、精力和进食次数每分钟保存到 `fly_world` NVS 命名空间。突然断电最多损失最近一分钟。本地模式无按键 90 秒后调暗屏幕，五分钟后熄屏，任意键唤醒。没有启用无线协议栈或音频播放。

## 神经模式

电脑运行 Xenova MaleCNS 演示，通过 USB 发送计算后的姿态和放电率摘要。卡片不运行完整连接组。166,700 个保留神经元及连接保持不变。动作使用增加了接触进食条件的演示性放电率解码器，不代表经过验证的果蝇生物力学。

电脑统一维护小岛和神经时钟。每经过 10 毫秒神经时间，电脑根据姿态与环境生成感觉输入、推进网络、解码动作，再更新世界。坐标限制在小岛范围内，不再循环。卡片接收绝对位置、进食状态和逼近阴影，不为达到显示帧率而虚构神经步骤。

默认环境不需要手动刺激。接触果实会刺激 LB3b/LB3c 糖味神经元；只有接触食物且 MN9 运动神经元活动时才计入进食，其他位置的放电不会消耗食物。逼近特征驱动 LC4/LPLC2，可触发逃逸。网页“显示阴影”只控制像素与三维渲染。实验工具中的“逼近刺激”按钮向已开启的视觉通路输入 0.65 秒神经时间的刺激，不定时重复，也不改变阴影显示设置。自主环境、视觉、味觉和实验性嗅觉使用独立开关。Pause 和 Reset 控制整个神经与环境时钟。

探索使用人工添加的 LC9 持续输入和可复现的 DNa02 转向偏置。饥饿和精力是工程定义的慢变量，饱食与饥饿、休息与活动使用不同切换阈值。它们调节输入和演示性身体解码器，不是原连接组中测得的内部状态。探索滑块调节这部分额外驱动。初始位置朝向附近果实，便于观察第一次接触，不代表已实现嗅觉导航。双侧 ORN_DM1 嗅觉输入与独立寻食辅助默认开启。辅助依据局部触角采样及近期变化调节 LC9/DNa02 输入，不读取食物坐标，也不直接移动身体。关闭辅助仍可保留嗅觉输入。这是人工策略，不代表连接组自发产生寻食能力。离线固件仍使用已有本地玩具规则。尚未实现视网膜级视觉或经过生物验证的自发行为。池塘、树、花和蘑菇是景物；岛边和岩石限制运动。

关闭自主环境并 Reset，可观察零输入基线。关闭味觉或视觉可对照相应反应。手动画笔刺激独立于环境开关，Clear 只清除手动刺激。完整网络可能慢于实时；场景和需求值均按神经时间推进。

收到新状态后进入神经模式。明确暂停仿真时，卡片保持神经模式并显示暂停。2.5 秒未收到有效状态后恢复本地行为，保留独立的本地饱食度与精力。电脑侧需求值随神经世界重置，不覆盖本地存档。重连同步新状态，不重放旧刺激命令。

## USB 协议

ASCII 帧以 `F1` 开头、换行结束，每帧最多 255 字节。启动后只有一个任务写 USB；初始化完成后关闭普通 ESP-IDF 日志。无效、非 ASCII 和超长行会被丢弃。

- `HELLO session` 建立主机会话；`READY boot 1` 确认应用协议。
- `STATE session sequence tick running x z heading height phase walking turning escape` 发送整数字段。位置、高度为毫米乘 1000；角度和相位为弧度乘 1000；tick 为仿真毫秒。walking 和 escape 为 Hz，turning 为度每秒。
- `WORLD session sequence tick running x z heading height phase walking turning escape feeding food energy shadow` 在 STATE 后增加绝对小岛状态。x/z 范围为 -13438..13438，格子坐标为 `2.5 + position_mm * 0.16`。feeding 范围 0..1000，food 和 energy 为 0..100，shadow 为 0 或 1。新版固件同时兼容 WORLD 与旧 STATE；旧 STATE 保留相对位移。
- `KEY boot sequence action` 请求动作；`ACK boot sequence` 确认浏览器已执行。重试沿用同一命令标识并去重。
- `STATUS` 报告模式、选择项、本地需求值、可用堆、帧数、队列溢出数、格子 u/v 乘以 1000、进食值、世界模式标志和最后接收序号。
- `CAPTURE` 返回 `IMAGE 240 320 I4 38400` 头及打包像素，使用 `fly_palette` 调色板。
- `BUTTON 0..3` 经过与上、下、确定、长按确定相同的输入处理流程。这是本地 USB 诊断命令。

## 构建与验证

使用 ESP-IDF 5.5.3，运行 `./tools/validate.sh`。应用必须位于 3 MB factory 分区内。对已有设备烧录时遵循[受保护 Flash 布局](development/engineering/protected-flash-layout.zh_CN.md)，禁止整片擦除。

主机测试覆盖协议分帧、数值边界、过期与重复消息、模式切换、进食与休息、绘制边界和桥接命令确认。模拟器检查不能证明 USB 电气行为、电池读数或实体按键输入。

美术为 `main/fly_view.c` 中的原创程序绘制像素画，没有使用 Minecraft 材质或第三方图片。神经数据和上游浏览器应用保留原有许可。

## 启动电脑端

运行 `tools/start-fly-world.command`，打开 `http://127.0.0.1:8768` 并点击 **Download & start**。桥接服务从仓库旁的 `fly-host/dist` 读取已构建的神经应用，从旁边的 `.toolchain` 使用 ESP-IDF Python 环境。模型资源全部来自本机，不需要云端推理 API。

用数据 USB 线连接一台 AI Passport。桥接服务发现 Espressif USB 设备后等待 Fly World 固件握手，网页横幅显示连接状态。保持神经仿真标签页打开、电脑唤醒。关闭标签页或停止桥接服务后，卡片回到本地模式。启动终端按 `Ctrl+C` 停止桥接；打开串口监视器或烧录前先关闭桥接。

原始演示可以继续运行在 8765 端口，只有 8768 端口的伴侣版本控制卡片。首个控制标签页持有有效会话期间，其他控制标签页会被拒绝。

电脑端测试在相邻的 `fly-host` 目录运行：`node --test tests/habitat.test.js` 验证确定性的环境规则；`node tests/closed-loop.mjs` 使用本地完整连接组验证自主接近、进食与离开、零输入、感觉通路关闭和突触传播关闭。这些是实现验证，不等同于生物学验证。

电脑观测站提供栖息地、神经活动与身体视图、按神经时间记录的曲线和行为事件，以及有上限的 CSV 导出。其他页面占用 USB 设备时，可在设备区点击“接管设备”明确切换控制权。桥接服务对该操作使用与普通状态消息相同的本地来源和状态校验。
